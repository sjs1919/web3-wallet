# 2026-10-24 项目初始化骨架踩坑记录

## 坑 1：Result.java 漏 import（编译错误）

- **日期/场景**：创建 common 模块 `Result.java` 时引用 `ErrorCode.SUCCESS` 但未 import，`mvn compile` 报 `cannot find symbol: variable ErrorCode`
- **根因**：跨包引用（`com.sjs.wallet.common.result` → `com.sjs.wallet.common.errcode`）漏写 import
- **教训**：record 类引用同模块其他包常量必须显式 import；写跨包引用时先自查
- **规避动作**：编译验证是必要门禁；CR 走读检查 import 完整性
- **是否升级**：一次性（低级错误），暂不升级

## 坑 2：WSL 无 Java/Maven + sudo 需密码

- **日期/场景**：编译验证前发现 WSL 无 `java`/`mvn`；`sudo` 需要密码且非交互环境无法输入
- **根因**：WSL 首次使用 Java 工具链未安装；默认用户无免密 sudo
- **教训**：WSL 可用 `wsl -d <发行版> -u root` 免密进入 root 执行安装，无需 sudo 密码
- **规避动作**：已装 JDK 17.0.20 + Maven 3.6.3（root，apt）
- **是否升级**：环境事实 → 已写入 CLAUDE.md「环境」节

## 坑 3：Maven 中央仓库下载慢

- **日期/场景**：首次 `mvn compile` 依赖下载慢（官方源）
- **根因**：repo.maven.apache.org 国内访问慢
- **教训**：配置阿里云 Maven 镜像显著提速
- **规避动作**：`/root/.m2/settings.xml` 已配 `maven.aliyun.com` mirror
- **是否升级**：环境事实 → 已写入 CLAUDE.md「环境」节

## 坑 4：Ubuntu 官方 apt 源慢

- **日期/场景**：`apt install openjdk-17-jdk maven` 下载慢（archive.ubuntu.com）
- **根因**：官方源国内慢
- **教训**：可换阿里云 apt 源（mirrors.aliyun.com）加速
- **规避动作**：本次未换（等待完成）；后续重装可换源
- **是否升级**：一次性，暂不升级
