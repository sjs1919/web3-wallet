# 错误码表（error-codes）

> **错误码唯一事实源**，与 `backend/common` 模块 `ErrorCode.java` 保持一致。新增错误码必须两处同步。
> 格式：5 位 = 3 位 HTTP 状态码 + 2 位业务细分码（如 `40001`）。

## 通用错误码

| 错误码 | HTTP | 含义 |
|--------|------|------|
| 0 | 200 | 成功 |
| 40001 | 400 | 参数错误 |
| 40101 | 401 | 未认证 |
| 40301 | 403 | 无权限 |
| 40401 | 404 | 资源不存在 |
| 50001 | 500 | 系统错误 |
